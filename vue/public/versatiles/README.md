# Kartenressourcen

Der Kartenstil und die Ortsmarker folgen dem kulturbytes-client:
https://github.com/sndcds/kulturbytes-client/tree/359a6cd84afdead4212ae8040e41d969e050b5b9/public

Die zum Stil passenden `basics`-Sprites stammen aus VersaTiles Style v5.13.1:
https://github.com/versatiles-org/versatiles-style/releases/tag/v5.13.1

Sie liegen lokal unter `sprites/basics/`, weil der ursprüngliche Serverpfad
inzwischen nicht mehr verfügbar ist. Die unveränderten PNGs und JSON-Metadaten
werden in einfacher und doppelter Auflösung mitgeliefert. Lizenz: CC0 1.0,
siehe `../licenses/versatiles-sprites.txt`.

MapLibre und dessen gebündelte Abhängigkeiten: siehe `../licenses/maplibre-gl.txt`.
Kacheln und Schriftzeichen werden weiterhin von den im Stil angegebenen Servern
geladen. Die OpenStreetMap-Attribution bleibt auf der Karte sichtbar.
